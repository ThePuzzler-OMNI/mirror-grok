# mirror-grok (Public)

Public home of the OMNI Mirror / Grok Mind-Meld templates, the HOG Model book, and the shared framework files.
Anyone may read and use what is here.

## Master Prompt (single source)

- **Current version:** 3.1live (2026-08-23)
- **Prompt text:** [masterprompt.txt](masterprompt.txt)
- **Version registry and changelog:** [MASTERPROMPT_VERSION.json](MASTERPROMPT_VERSION.json)
- Same text on the web: https://onemissionnetworkandinstitute.org/masterprompt

Older launch files ([Mirror-Grok-Launch.md](Mirror-Grok-Launch.md), [Mirror-Grok-Launch-v2026-07-29.md](Mirror-Grok-Launch-v2026-07-29.md)) are kept for history and are superseded by `masterprompt.txt`.

## Structure

| Path | Purpose |
|------|---------|
| `masterprompt.txt` | Current Master Prompt (single source) |
| `MASTERPROMPT_VERSION.json` | Master Prompt version registry |
| `Core-Framework/` | Five Gardens, 13 Shared Values, One Mission Statement, HOG Model book and status |
| `Book-Wiki/` | Navigation and comment pages for the HOG book |
| `Metrics/` | Daily monitor log and metrics report templates |
| `Systems/` | Conversation architecture, presence, monitors |
| `Transcripts/` | Transcript rules, template, and a short format example |
| `Archive/` | Earlier book builds |

## Private material

Full transcripts and personal records are not in this repository. They live in the steward's private repository (OMNI-Grok), which is steward-only and cannot be opened by other runners. The Master Prompt works for everyone with the public files above.
